WordBuds

CS495 Capstone Project

Wordbuds is a mobile app designed for parents to track and visualize their child's language development through daily logs that includes photos, videos, and audio. These entries are automatically categorized by part of speech, while push notifications encourage consistent data entry. The platform features an analytics dashboard that compares a child's progress against developmental norms using various data visualization techniques. Built to meet strict IRB compliance standards, Wordbuds utilizes Firebase for secure storage and includes a dedicated portal for authorized researchers, like the project sponsor Dr. Hsin, to access data for future academic study.
