# Dependency Management

This project contains many dependencies. One of the most important issues that will come up in the future because of this is the migration to Built-in Kotlin. This does not need to be done until the AGP (Android Plugin) is at version **9.0.0 or later**. The current version of AGP is **8.11.1**. A tutorial for this migration is linked below. This may not be an issue during the Fall 2026 semester, however may become one for future semesters.
